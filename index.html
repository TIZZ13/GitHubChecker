Проверь проект
до того, как его увидят

Вставь ссылку на GitHub-репозиторий. Получи оценку по 100-балльной шкале, понятный список проблем и готовые промпты для своего ИИ-агента.

Работает с публичными репозиториями. Приватные — добавь токен в настройках.

Что проверяется

Безопасность 25

Секреты в коде, .env в репозитории, приватные ключи, конфиги с паролями.

Запуск 20

Инструкция «как запустить», манифест проекта, lockfile, точка входа, CI.

Качество 15

Тесты, линтер, проверка тестов в CI, гигантские файлы в репозитории.

Репозиторий 15

Лицензия, описание, темы, README на английском, картинки.

Продукт 15

Демо-ссылка, релизы, CHANGELOG, шаблоны issue, документация.

Доверие 10

Контрольные суммы, политика безопасности, CONTRIBUTING, контакты.

Как это работает

  1. Читает публичные данные. Сайт делает несколько запросов к GitHub API: описание, файлы, README, релизы.
  2. Прогоняет правила. Это детерминированные проверки, а не ИИ: одинаковый репозиторий всегда получает одинаковый балл.
  3. Объясняет и даёт промпт. Каждая проблема — человеческим языком, с готовым текстом для твоего агента.

Приватность

Ничего не отправляется никуда, кроме api.github.com. Нет аналитики, нет аккаунтов, нет базы данных. Токен, если добавишь, хранится только в твоём браузере. Найденные секреты не показываются в интерфейсе и не логируются.

What gets checked

Security 25

Secrets in code, committed .env, private keys, configs with passwords.

Runnable 20

Install/run instructions, manifest, lockfile, entry point, CI.

Quality 15

Tests, linter, tests running in CI, huge files in the repo.

Repository 15

License, description, topics, English README, images.

Product 15

Demo link, releases, changelog, issue templates, docs.

Trust 10

Checksums, security policy, contributing guide, contacts.

How it works

  1. Reads public data. A few GitHub API requests: description, file tree, README, releases.
  2. Runs rules. Deterministic checks, not AI: the same repository always gets the same score.
  3. Explains and hands you a prompt. Every issue is plain language, with text you can paste into your agent.

Privacy

Nothing is sent anywhere except api.github.com. No analytics, no accounts, no database. A token, if you add one, stays in your browser. Detected secrets are never rendered or logged.

Настройки

Нужен только для приватных репозиториев и лимита 5000 запросов в час вместо 60. Хранится в localStorage этого браузера и уходит только на api.github.com. Нужен scope public_repo.
